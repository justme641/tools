匯出

把「主分類／次分類／播放清單」與「Podcast 訂閱」存成一個 JSON 檔。本地檔案只記錄檔名與大小，檔案本身留在各裝置的媒體庫。

匯入

網站預設清單

首次開啟時，會自動讀取與本頁同一個資料夾的 mirror-data.json 作為預設清單（只在這台裝置還沒有任何資料時自動載入一次）。之後也可以手動載入並合併：

媒體庫（存在這台裝置）

關於資料儲存

  • 所有資料只存在「這台裝置的這個瀏覽器」，不會上傳到任何伺服器。
  • 清除網站資料、換瀏覽器或換手機，資料就會消失，請定期匯出備份。
  • 換新裝置時：匯入備份檔後，清單裡的本地檔案第一次播放會請你選一次檔案，之後就會記在那台裝置的媒體庫。
📜 修改歷程紀錄 (Changelog)
v1.0 (2026-10-23)
  • 創立專案：實現本地影音與 YouTube 嵌入鏡像播放器、全螢幕、循環播放及速度調節。
  • 介面調整：優化按鈕配色，將標題簡化為「影音播放器」。
  • 功能擴充：新增本地 MP3/M4A 音訊播放支援。
  • 下載整合：新增點擊複製網址並嘗試喚醒 YTDLnis App 功能，並在介面加入官方 GitHub Releases 下載專屬直達捷徑。
  • 播放優化：支援影音直連網址；YouTube 改用 IFrame API，速度與循環可直接調整且不需重新載入；記住鏡像、循環與速度設定；新增快捷鍵、手機鎖定畫面媒體控制、A-B 區段重複、播放速度 1.5x／2.0x、可一次選取多個本地檔案連續播放；載入失敗時顯示提示。
  • 媒體庫：本地影音可存入瀏覽器媒體庫（IndexedDB），下次不用重新選檔即可直接播放。
  • 功能擴充：新增自訂播放清單，可建立主分類與次分類，分類與項目皆可改名、刪除、調整順序，項目可移至其他次分類，並可連續播放整份清單。
  • 資料管理：新增匯出／匯入（合併或取代）備份檔；首次開啟自動讀取同資料夾的 mirror-data.json 作為預設清單，並可手動載入合併。
  • 功能擴充：新增 Podcast 訂閱清單（搜尋或貼上 RSS）、單集播放、加入播放清單，以及單集音訊下載（來源允許時直接下載，否則改開新分頁）。
